bbweb Installer

program

Lightweight web installer and updater for supported bbweb projects. Manifest-driven, with self-update and update checks.

Download bbwebInstaller.exe (0.37MB) GitHub

v0.1.1 · Windows

Features

Install and update

Install supported bbweb projects and keep them up to date using a remote manifest. Includes self-update for bbweb Installer.

Supported by bbweb Installer

  • 10tweaker, FlaxyIDE, LunaClean, bbruntime, NextJPPM

Logon update checks

Optional scheduled check at user logon shows a notification when updates are available and exits when there is nothing to do.

Lightweight

Single ~0.37 MB executable with a simple Win32 UI, focused on doing one job well.

CLI and automation

Command-line options let apps and scripts check or update a specific product, use logs, and override the manifest source.
