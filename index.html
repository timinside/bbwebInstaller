bbweb Installer

program

Web installer for some of my projects. Download the latest release or build an app from source when supported.

Download bbwebInstaller.exe (8MB) GitHub

v1.0_beta1 (W.I.P) · Windows

Features

Install supported projects

Get the latest release of supported bbweb projects through a small installer.

Supported by bbweb Installer

  • 10tweaker, FlaxyIDE, LunaClean, bbruntime, NextJPPM

Build from source

Where available, build an app instead of downloading a prebuilt release. Building may include unstable scripts. It's supported by Open-Source projects only.

Lightweight

Small download size focused on doing one job well.

Work in progress

bbweb Installer is still in development, so features and supported projects may change.
